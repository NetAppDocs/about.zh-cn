[[mcp-endpoint]]
== MCP 端点

docs.netapp.com MCP 服务器具有通过标准 MCP 接口公开 NetApp 文档的远程 HTTP 端点。Visual Studio Code 中的 GitHub Copilot、Claude Desktop、Cursor 和自定义 Python 代理框架等客户端应用程序可以通过受支持的 MCP 客户端连接到它。

.HTTP 端点
`\https://docs.netapp.com/mcp`

以下示例格式用于在 Visual Studio Code 中使用  `mcp.json` 文件配置 MCP 服务器。有关其他受支持的 MCP 客户端的信息，请参阅 link:mcp-server-get-started.html["开始使用 docs.netapp.com MCP 服务器"]。

[source, json]
----
{
  "servers": {
    "netapp-docs-mcp": {
      "type": "http",
      "url": "https://docs.netapp.com/mcp",
      "headers": {
        "Ocp-Apim-Subscription-Key": "${input:Ocp-Apim-Subscription-Key}"
      }
    }
  },
  "inputs": [
    {
      "type": "promptString",
      "id": "Ocp-Apim-Subscription-Key",
      "description": "Enter your access key",
      "password": true
    }
  ]
}
----


[[tools]]
== 工具

docs.netapp.com MCP 服务器提供了一个用于文档发现和检索的小型专用工具集。在客户端中调用 MCP 服务器时，无需指定工具。AI 客户端根据查询选择正确的工具。

服务器当前提供了以下工具：

* `netapp_docs_ask`：使用检索增强生成工作流从发布到 docs.netapp.com 的内容中生成答案。
* `netapp_docs_search`：使用关键字和自然语言查询发现相关 NetApp 文档页面。
* `netapp_docs_fetch`：检索特定文档页面或文章的结构化内容。
* `health_check`：验证 MCP 服务器的可用性。
